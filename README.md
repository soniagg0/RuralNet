# BioLoRa Sync 

Biomedical data monitoring system using **BITalino**, **LoRa** for long-range transmission, and a **Raspberry Pi/Arduino** architecture with bidirectional flow.

##  Overview
This project captures physiological signals via BITalino and transmits them using LoRa technology. It features a bidirectional data flow between the sensor nodes and a centralized database for real-time health monitoring.

##  Tech Stack
* **Hardware:** BITalino, Raspberry Pi, Arduino, LoRa Modules.
* **Languages:** Python, C++, SQL.
* **Infrastructure:** Bidirectional Database & Web App.

##  Repository Structure
* `/BACKEND`: Server logic and database management.
* `/FRONTEND`: Web interface for data visualization.
* `/Código Arduino final`: Sensor acquisition and LoRa transmission code.
* `/Raspberry Data Processing`: Gateway logic and data handling.
